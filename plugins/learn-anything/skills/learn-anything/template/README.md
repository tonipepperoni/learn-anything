# Study app

A self-contained study + quiz app generated by
[learn-anything](https://github.com/tonipepperoni/learn-anything). The questions
and guides live in a SQLite database queried in the browser (sql.js), so it runs
offline with no server.

## Open it

Just open **`index.html`** in a browser. (Or serve it:
`python3 -m http.server 8000` then visit `http://localhost:8000`.)

## Themes

Click the **⚙ gear** in the top bar to switch themes — Monokai, Dim, Nord,
Dracula, Light, Solarized Light. Your choice is remembered per browser.

## Edit the content

- `study.config.json` — title, topics, domains, levels, badges, exam settings
- `content/<NN-slug>/questions.json` — the questions for a topic
- `content/<NN-slug>/guide.md` — the study guide (Markdown, with SVG diagrams)

After editing, rebuild (needs **Node ≥ 22**, no install required):

```bash
node build/build.mjs
```

## Update the app

To pull the latest app template (design, features, themes, bug fixes) without
touching your content or progress:

```bash
node update.mjs
```

Your saved progress lives in the browser, so it survives rebuilds and updates.
